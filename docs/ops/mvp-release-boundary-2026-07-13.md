## 2. IN — 첫 릴리즈 범위

**크리에이터**
- 셀프가입 → **크리에이터 모드 전환/등록** (프로필: 이름·핸들·소개·커버·아바타)
- **디지털 상품** 등록 / 판매 상태 관리 (스튜디오)
- 19+ 상품/콘텐츠 = 성인 표시(작성)

**팬**
- 가입/로그인 (**팬 모드** 기본) · 크리에이터 페이지 열람 · 디스커버리
- 디지털 상품 상세 → **단건 구매(실 PG)** → 이용/다운로드 → 주문내역
- 19+ 콘텐츠 열람 = **성인 인증 게이트**

**결제 · 인증**
- 실 PG 결제(카드·카카오페이·계좌) **승인/캡처/웹훅** + 환불(운영 수동)
- **성인(19+) 본인인증 실연동**
- 필수 정책: 이용약관·개인정보처리방침·환불정책·통신판매중개 면책

**운영**
- 클라우드 **프로덕션 배포** + 도메인 + SSL
- 최소 정산 가시성 (자동 지급 X, 원장/집계만)

## 3. OUT — v1.1 이후로 미룸

멤버십/구독(정기결제) · 실물 굿즈/배송 · 후원·퀘스트·1:1 메시지 · 자동 정산 지급 · 모바일 앱 · 스튜디오 고급 애널리틱스 · 크리에이터 초대/심사제(현재는 셀프가입)

## 4. 코드 현황 (이미 있는 것 / 신규)

| 영역 | 상태 |
|---|---|
| 크리에이터 페이지·스토어·상품·체크아웃 화면(웹) | ✅ 구현됨 (mock 결제) |
| 계정 role(fan/creator)·스튜디오 프로필 편집·OTP 가입 | ✅ 서버 존재 → **모드 분리 UX만 신규** |
| 19+ 게이팅 인프라 (adult_verified·콘텐츠 게이트·AgeGate) | ✅ 코드 有(mock KYC) → **실 본인인증 provider만 신규** |
| **실 결제 승인/캡처/웹훅** | ❌ **신규 구축** (현재는 주문 즉시 PAID = mock; 인증/캡처 플로우 자체가 없음) |
| 배포 (AWS terraform ECS) | ⚠️ 코드 有, **apply 안 됨** |

★결제는 "mock 교체"가 아니라 **주문 라이프사이클 신규(PENDING→승인→PAID)** + PG 어댑터 구축. `PaymentTokenizer(ABC)`/`PaymentAttempt` 원장/provenance=external 로 **자리는 잡혀 있음**(bounded).

## 5. 임계경로 & 외부 의존성 (★일정 리스크)

1. **PG 가맹 심사** — 사업자등록·통신판매업 신고 전제. 영업일 **1~2주+**. 코드로 단축 불가 → **즉시 신청.**
2. **성인 본인인증 provider + 법무 사인** — D2로 추가된 두 번째 long-pole. 법무(청소년보호법·정보통신망법 §42-3/§44-2·n번방방지)는 우리가 단축 불가.
3. **배포 타깃** — Next.js SSR = **클라우드 필요**. Cafe24 "웹호스팅"(정적/PHP) 단독으론 SSR 미구동.

## 6. 권고

- **PG = 포트원(구 아임포트)** — **카드+카카오페이+계좌 결제 + 19+ 본인인증을 하나의 통합**으로 커버 → D1(결제)과 D2(본인인증) 두 long-pole을 **단일 계약/연동**으로 해결. 대안: 토스페이먼츠(결제) + 별도 본인인증 provider.
- **배포 = 클라우드** (AWS terraform 이미 有 / 또는 Vercel류).
- **디자인** = 브랜드색 #5A4DF0 확정 · Pretendard 설치/실이미지만 남음(릴리즈 블로커 아님).

## 7. 빌드 계획 (병렬 레인)

- **A. 셀프가입 + 크리에이터/팬 모드** — 외부 의존성 0 → **즉시 착수**
- **B. 결제 플로우 신규** — provider-agnostic 승인/캡처 경계 + 포트원 어댑터를 **sandbox 키로 선행** (심사 완료 시 실 키만 전환)
