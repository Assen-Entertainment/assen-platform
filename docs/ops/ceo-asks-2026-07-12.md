# 대표 요청사항 — 프로덕션 활성화를 위해 필요한 결정·제공 (2026-07-12)

플랫폼 코드/CI는 성숙 단계이나, **실제 프로덕션 가동은 회사/대표만 제공할 수 있는 외부 계약·클라우드·계정·결정에 막혀 있다.** 아래는 엔지니어링이 더 진행할 수 없고 **대표의 결정·제공이 있어야 풀리는 항목**만 모은 것이다. (엔지니어링으로 처리 가능한 잔여는 별도 — 여기 없음.)

각 항목: **무엇이 풀리는지** / **대표가 할 일**.

---

## A. 클라우드 인프라 프로비저닝 — 프로덕션 배포의 최대 블로커 (E10)
> IaC(terraform)·배포 워크플로·이미지 퍼블리시는 **작성·검증 완료**됐으나, 적용할 **실 AWS 환경이 없다**(`docs/adr/0003-hosting-aws.md`: AWS Seoul ECS Fargate). 아래가 있어야 `terraform apply` + 실 배포가 가능하다.

| # | 필요한 것 | 대표가 할 일 |
|---|---|---|
| A-1 | **AWS 계정 + 프로비저닝 승인** | AWS 계정 확보/지정, ap-northeast-2 사용 승인 |
| A-2 | **네트워크(VPC/서브넷)** | 기존 VPC + 퍼블릭/프라이빗 서브넷 제공(또는 신규 생성 승인) — terraform 입력 |
| A-3 | **DB/캐시**: RDS(Postgres)·ElastiCache(Redis) | 프로비저닝(또는 관리형 사용 결정) + 접속정보를 Secrets Manager에 저장 |
| A-4 | **시크릿 배치** | `SECRET_KEY`·`DATABASE_URL`·`REDIS_URL`·`PHONE_IDENTIFIER_HMAC_KEY`(≥32B) 등을 Secrets Manager/SSM에 저장 |
| A-5 | **terraform state 백엔드** | S3 버킷 + DynamoDB 잠금 테이블(state 저장용) 생성 |
| A-6 | **도메인·TLS** | 프로덕션 API 도메인(예: `api.assenent.com`) + ACM 인증서 + DNS |
| A-7 | **GitHub 배포 게이트 설정** | ① Environment `production` 생성 + **승인자 지정** ② OIDC 배포 롤(`AWS_ROLE_TO_ASSUME`) ③ terraform 출력값을 repo 변수(`ASSEN_ECS_*`)로 등록 |
| A-8 | **웹 배포 타깃 결정** | 웹을 **Vercel vs ECS** 중 결정(E10) + 결정 시 `vars.PROD_API_URL` 설정(→ 웹 이미지 퍼블리시 활성) |

## B. 실 외부 서비스 계약 (의사결정 게이트 — 현재 전부 mock/fail-closed)
> 각 경계는 코드로 완비되어 있고 **flag만 닫혀 있다.** 실 계약/연동 자격이 있어야 활성화된다. **대표(+법무) 명시 승인이 있어야 각 게이트를 연다.**

| # | 서비스 | 대표가 할 일 |
|---|---|---|
| B-1 | **결제(PG)** | 결제대행사(PG) 계약 + 실 연동 승인(결제 활성화 = 매출 시작). 현재 무결제 mock. |
| B-2 | **본인인증(KYC/성인)** | 인증기관(NICE/PASS/KCB/아이핀) 계약 |
| B-3 | **SMS(OTP)** | 문자 발송사 계약(가입/로그인 OTP 실발송) |
| B-4 | **푸시(FCM/APNs)** | Firebase 프로젝트 + APNs 인증서 |
| B-5 | **오브젝트 스토리지/CDN** | S3 버킷 + CloudFront(업로드 미디어 저장/서빙) — 현재 미구현 |
| B-6 | **이메일** | 발송 서비스(SES 등) — 현재 미구현 |
| B-7 | **인앱결제(IAP)** | 앱스토어/플레이 인앱결제 정책 결정(모바일 유료) |
