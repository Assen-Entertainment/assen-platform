# 하츠코이 시그니처 디자인 v1 — "밋밋함"의 해법

15개 플랫폼(4개 카테고리: F&B·레트로 / 게임·수집형 / 캐릭터 IP·서브컬처 / 콘카페 대조군)을 "성격 → 구현 장치"로 분해한 결과. 상세 분해와 출처는 autoresearch 런 로그(`.omc/autoresearch/hatsukoi-design-signature/`) 참조.

## 0. 진단 — 왜 밋밋한가

현재 26화면은 토큰·컴포넌트 차원에서 정합하지만 "일반적인 라이트 파스텔 앱"이다. 분해 결과의 결론: **개성은 컬러가 아니라 ①명명(어휘) ②한두 문턱의 연출 ③실패의 처리에서 나온다.** 15개 플랫폼 전부가 이 세 층위에서 성격을 구현했고, 우리는 세 층위가 전부 표준값이다.

## 2. 하츠코이 시그니처 3+2 (구체 스펙)

### S1. 「두근」 시스템 — 첫사랑 어휘 전면 치환 (명명이 1차 디자인)
- 포인트 → **두근** ("두근 +50"), 예약 → **약속**, 방문 기록 → **만난 날**, 체키 앨범 → **추억**, 위시 → **마음에 담아두기**
- 호칭은 표준 존대 유지(큐어메이드 이중 구조: 어휘는 세계관, 호칭은 격식) — 닉네임 호명 없음
- 카피 규약: 평소 건조한 정보체, **완료 모먼트 한 곳만 들뜸 허용**("예약됐어요!"), 빈/실패 상태는 누적 축하형·시스템 사과 어법("이번엔 준비하지 못했어요"), 마감·손실·죄책감 어휘 금지
- 적용 위치: 전 화면 카피 + F3(두근 내역) + B2/D2 토스트. 공수: 카피 시트 1장 + setText 일괄

### S2. 모션 토큰 3종 — 연출은 두 문턱에만 (토스 교훈: 스펙이 시그니처를 만든다)
| 토큰 | 스펙 | 적용 |
|---|---|---|
| `heart.confirm` | 크림 플래시 80ms → 하트 윤곽 스트로크 드로잉 250ms → 차임 1음+햅틱 1펄스 (~400ms) | 체크인(B1→B2), 예약 확정, 가입 완료 — 전 완료 모먼트 공통 |
| `film.develop` | 배출 400ms(오버슈트) → 불투명도 현상 1.2–1.8s(햅틱 틱 2회) → 도장음 | 체키 획득. 등급 텔=필름 테두리 파스텔색. 첫 획득만 풀 연출, 재획득은 탭 스킵 |
| `stamp.thunk` | 도장 하강 → 눌림(잉크 번짐 1프레임) → 카드 2px 출렁 → 정착 (~350ms) + '쿵' 사운드 1개 | 스탬프 적립, 도감 등록 |
- 원칙: 이 3개 외 화면 전환은 표준 모션 — **대비가 시그니처를 만든다** (디즈니: 입장 한 곳에 예산 집중)
- 그라디언트·발광 금지와 호환 (불투명도·물리 모션만)

### S3. 성냥갑 티켓 양식 + 크림소다 3색 규칙 (준킷사 문법)
- 티켓/쿠폰/체키권 템플릿: 세로 직사각 + 1px 솔리드 테두리 프레임 + 점포 로고타입 + **발행 No.**(4자리) — 수집 의식과 직결
- 컬러 서사: 크림(베이스) + 시즌 파스텔 1색(소다) + **체리 레드 도트는 알림·완료 표시 전용** — 빨간 점이 '체리'라는 세계관 장치가 됨
- 적용: CouponTicketSet·EntryTicket 개편, CountBadge 의미 부여. 공수: 컴포넌트 2종 수정

### S4. 방문 후 「오늘의 기록」 reveal (포켓몬 슬립 — 보상은 돌아본 순간에)
- 방문일 다음 앱 오픈 1회 한정, 고정 순서 3카드: ①오늘 날짜 타이포 카드 → ②두근 카운트업 → ③오늘의 스탬프 도감 등록(희귀도 별)
- 세계관 논리: 첫사랑은 '집에 와서 곱씹는 밤'에 완성된다. 과몰입 푸시 없이 재방문 리듬 생성
- 적용: 신규 화면 1종 + 주간 마디("이번 주의 첫 페이지") 카드

### S5. 엇갈림의 처리 (치이카와+TDR — 실패를 숨기지 않는다)
- 품절·마감·낙선: 회색 비활성 대신 **기울어진 하트 윤곽 + "다음엔 꼭"** 류 짧은 카피
- 당첨/낙선 어법 분리: 선언형("자리가 마련됐어요") / 시스템 사과형
- 적용: EmptyState·TimeSlotChip(full)·이벤트 낙선 상태. 첫사랑의 '아쉬움'은 정서 자산

## 3. 보조 적용안 (우선순위순)

6. **성장하는 회원증**: 방문 누적에 따라 카드의 하트 기하 모티프가 변형(윤곽→점선 채움→실선→이중) — 산리오 회원증의 기하 번안. 등급 배지 불요
7. **학사일정 4시즌**: 입학식(봄)·여름방학·문화제(가을)·졸업식(겨울), 시즌당 액센트 1색+스탬프 1종만 교체, 코스터→체키 티켓→앱 3표면 동기화, 시즌 첫날="개학일"
8. **스탬프 도감 + 희귀도**: 요일·계절·이벤트별 변형 기하 스탬프, 별 1~3, 미획득은 파스텔 실루엣("아직 만나지 못했어요")
9. **'오늘의 이름표'**: 체크인 시 학교 명찰형 태그 발급(학년-반 칸 양식, 타이포만) — LBM 이름 스티커의 번안
10. **한 글자 타이포 장치**: 화면 타이틀의 한 글자만 손글씨체+파스텔 스티커 사각 (P5 문법의 큐트 번역) — 캡처만으로 식별
11. **하지 않는 것 목록 명문화**: 닉네임 호명 안 함·답장 보장 안 함·푸시로 조르지 않음·과한 이모지 안 씀 — 기존 제약을 큐어메이드식 포지셔닝 자산으로 전환, 브랜드 문서화
12. **도감 실루엣 빈칸**(ACNH): 체키 도감 미획득 칸에 시즌 라벨 — 당기는(pull) 재방문 동기

## 4. 금지 패턴 정합성

전 항목 검증: 그라디언트→솔리드/불투명도, 블랙골드→파스텔 단계, 친밀감 연출→어휘·격식 이중 구조(호명 없음), 과몰입 푸시→reveal·도감의 pull 동기, 죄책감 어휘→누적 축하형. references.md 금지 10종과 충돌 0건.
