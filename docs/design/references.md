# 디자인 레퍼런스 보드

조사일 2026-06-11. 3개 라인 병렬 조사(일본 메이드카페 공식 앱 / 한국 팬 플랫폼 / 표준 패턴·토큰 체계) 요약.
신뢰도: 각 항목은 1차 소스 확인 기준으로 채택했고, 픽셀 단위 시각 디테일 일부는 "미확인 — 실기기 QA 필요"로 남아 있다.

## 1. 일본 메이드카페 공식 앱

### @home cafe 앱 (2024-12 출시, iOS 4.78★)
- 본질: 바코드 회원증이 아니라 **방문(ご帰宅)을 포인트·로그·트로피로 기록하는 추억 아카이브** + 원격 줄서기.
- 수집 화면 실측: 트로피/배지 세그먼트 탭 + 필터 칩(체키/콜라보체키/게임/이벤트/내점) → 진행 바 카드 → **획득 이력에 메이드 사진+말풍선 코멘트+그날의 방문 로그 링크**(트로피↔방문↔메이드 상호 연결) → 메이드별 3열 그리드.
- 등급 보상이 시각적: 랭크가 오르면 **체키 낙서 자유도**가 풀림(고정 문구→자유) — "등급=시각적 자유도" 설계.
- 컬러: 솔리드 미디엄 핑크(#EA6D9E 추정, 공식 CSS #ff85a2) + 톤온톤 하트 패턴. 쿠폰은 절취선 티켓 메타포, 생일은 풀스크린 모달.
- 안티패턴(1★ 리뷰): 혼잡 시 서버 다운, 가입 실패, 알림 일괄 강제(굿즈 알림 끄기 불가), 포인트 단위 혼용(멤버십 Pt vs 수집 Pt).

### maidreamin 앱
- 등급 체계(공식 검증): 칭호 LV1~4(입국 횟수) + VIP 랭크(반기 포인트: VIP→HERO→LEGEND→EMPEROR→STELLAR→GOD). **랭크 카드는 실물 발송**, 앱에는 현재 랭크+다음 랭크까지 진행 표시.
- 카드 비주얼: 마블 텍스처+골드 프레임+세리프 카드명. **상위로 갈수록 블랙+골드로 수렴** — 우리 라이트 무드와 충돌하므로 반면교사.
- 타이포 투트랙: UI는 라운드 고딕(M PLUS Rounded 1c), 랭크 카드만 세리프 — "귀여움↔격식" 분리.
- 컬러: 핫핑크 #ff68a7 + 딥 인디고 #331f88 듀오톤, 골드는 랭크 전용.

### 일본 회원증 일반 관례
- **등급 3종 세트**: 등급명 뱃지 + 다음 등급까지 진행 바/도넛 + 등급별 카드 스킨 변화 (스타벅스 재팬 Gold 애니메이션 카드, MUJI passport 도넛).
- **바코드 퍼스트**: 기동→1탭 제시, 바코드 화면 자동 휘도 상승(표준 문법), 오프라인 캐시 표시.
- instax UP!: 체키 컬렉션 **이중 뷰**(정돈 그리드 + 흔들면 셔플되는 박스 뷰), 추시별 앨범.
- 콘카페 화이트라벨 앱 표준: 테마 히어로 + 아이콘 그리드(포인트/스탬프/쿠폰/출근캘린더/예약) + 회원증 탭(카드+대형 바코드).
- 발견: **체키 원본의 인앱 앨범은 일본 공식 앱에도 부재 — Assen이 만들면 차별화 포인트.** "콘카페 공통 회원증 포털"(コンコネ)은 출시 전 — 시장 공백.

## 2. 한국 팬 플랫폼

### 버블 (DearU)
- "1:N을 1:1처럼" 장치 (NN/g 공식 분석): 카카오톡 모방 UI, %username 닉네임 치환, 일괄 읽음을 개별 읽음('1' 배지)처럼 연출, D+n 카운터+100일 단위 커플 기념일식 축하, 해지 시 깨진 하트 — **상당수가 Company-OS 카피 제약(사적 친밀감·답장 보장 암시 금지) 위반 → 피할 패턴**.
- 가격: 인앱 5,000원/웹스토어 4,500원 이중 가격(2025-07).

### 위버스
- 멤버십 이원화: 연간 팬클럽 + 디지털 멤버십(월 2,700~5,400원, 카드+광고 제거). 닉네임 옆 멤버십 마크.
- 젤리 코인: 웹 충전 보너스로 웹 우대. **"앱 해지→7일 내 웹 재구독 시 구독일 유지"를 공식 가이드** — 이중 트랙 전환 동선의 모범.
- 온보딩: 알림 → 번역 언어 → 관심 아티스트 선택 — "가입"이 아니라 "선택"의 흐름.
- 아티스트/팬 콘텐츠 탭 분리. 알림 2단 토글(아티스트별×활동별) — 단 멤버별 필터가 유료 혜택인 건 반면교사.
- 브랜드: MINT+DEEP NAVY, 기본 라이트(다크는 2024-10에야 추가).

### 기타
- fromm: 웹 전용 "BFF 패스"로 웹 결제를 혜택 업그레이드로 포장. 답장 횟수 판매는 제약 위반 영역.
- fab: 포인트 종량제(열람당 과금) — 비용 예측 불가로 팬 반발, 검증된 실패 패턴.
- Likey: 멤버십 정기결제는 웹 중심, 하트(후원)만 인앱 — 웹 결제 동선 선례.
- b.stage: 멤버십 등급 최대 10단계 + 기능별 권한 차등 — 단일 브랜드 구조의 직접 레퍼런스.

## 3. 표준 패턴·토큰 체계 (상세는 [[tokens]])

- W3C DTCG Design Tokens Format 2025.10 첫 안정판 → tokens.json 포맷 채택. Tokens Studio로 Figma 동기화, Style Dictionary v4로 Dart 생성.
- Flutter: `ColorScheme.fromSeed`는 시드 색이 결과에 없을 수 있음(공식 명시) → **수동 ColorScheme** + 커스텀 토큰은 ThemeExtension.
- 회원증 카드: Apple PassKit storeCard 5층 구조(로고/스트립/주필드/보조필드 최대 4/바코드)가 업계 문법.
- 체키 그리드: instax mini 실측 비율(필름 54×86, 이미지 46×62) 기반 세로 카드 2~3열.
- 파스텔 접근성: 파스텔 텍스트는 전면 실패(예: #FFD1DC 흰 배경 1.36:1) → **배경·필 전용 + 동일 hue 다크 잉크 텍스트**(6.18:1). Radix 12단계 모델, 파스텔 인접 경계는 보더 필수.
- 타이포(라이선스 검증 완료): Pretendard(OFL) + 카페24 써라운드(무료·임베드 허용) + 갈무리/Neo둥근모(OFL 픽셀) — 전부 앱 임베드 안전. 둥켈산스는 유료라 제외.
- 모티프 구현: 티켓 절취선(ticketcher 패키지/CustomClipper), 우표 테두리(borders StampBorder), 체키 프레임(패키지 불필요 — 비율 컴포넌트), 스탬프 카드 7~10칸 최적.

## 채택 패턴 (종합 12)

1. 회원증 = 실물 카드 비율 + PassKit 5층 구조 + 등급별 카드 스킨(솔리드 파스텔 색면+모티프 차등으로 번역)
2. 등급 3종 세트: 뱃지 + 진행 도넛/바 + 카드 변화
3. 등급 보상 = 시각적 자유도 (체키 프레임·카드 커스텀 옵션 해금)
4. 방문 로그 = "그날 만난 캐스트" 기록, 방문↔캐스트↔체키 상호 링크
5. 체키 컬렉션 이중 뷰(그리드+박스 셔플), instax 비율 프레임 — 차별화 핵심 화면
6. 수집 필터 칩 + 캐스트별 진행 그리드
7. QR/바코드 1탭 + 자동 휘도 + 오프라인 캐시
8. 쿠폰 = 절취선 티켓, 생일 = 풀스크린 축하 + 체키 티켓 선물
9. 타이포 투트랙: UI 라운드 고딕(써라운드/Pretendard), 격식 표면(등급명·증서)만 세리프 — 랜딩 세리프 워드마크와 연결
10. 솔리드 키컬러 + 톤온톤 모티프 패턴, 모티프 색 3색 이내
11. 캐스트별 컬러 시스템(응원색 문화) — 파스텔 멀티컬러 팔레트를 캐스트 아이덴티티로 활용
12. 온보딩 = "선택"(알림→최애 캐스트), D-day는 **장소·방문 중심 프레임**("n번째 방문")으로 치환

## 금지 패턴 (종합 10)

1. 닉네임 치환 호명, 2. 읽음 표시 환상, 3. 답장 권한 판매(글자수/횟수 확장) — 이상 카피 제약 직접 위반
4. 해지 화면 감정 자극(깨진 하트) — NN/g 명시 다크패턴
5. "커플 기념일" 프레임의 D-day
6. 상위 등급 = 블랙+골드 클리셰 — 상위 등급도 어두워지지 않는 위계 언어(우표 색·스탬프 밀도·프레임 장식 증가) 정의
7. 포인트 단위 혼용(통화 1개, 수집 진행은 개수/%)
8. 알림 일괄 강제(캐스트별×유형별 2단 토글 기본 제공, (광고) 푸시 분리 — 정보통신망법 §50)
9. 종량제 열람 과금(fab 실패 사례)
10. 온보딩 마찰(필수 정보 소급 확대, 실물 연동 강제) — 게스트 모드+점진 등록
