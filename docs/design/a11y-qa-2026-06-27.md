## 최종 결과

## 적용 방식
- **소스**: `assen-platform/docs/design/tokens.v2.json` (Primitives ink.500/ink.400/red/green/amber, Semantic onPrimaryContainer).
- **미러**: Figma `Snd7m8KauF51QBZL5LWuGu` Primitives/Semantic 변수 값 동기 → **변수 바인딩 컴포넌트에 자동 전파**(개별 수정 불필요).
- hue 유지하며 최소 darken(색 정체성 보존).

## 후속
- 코드 레인 `melos run codegen` 시 동일 값 자동 반영(tokens.v2→tokens.json→Dart).
- 향후 신규 색 추가 시 본 QA(대비 계산) 재실행 권장. AAA(7:1) 필요 표면은 별도 검토.
